# Helfy

Landing page for DoktorABC. HTML, CSS, and vanilla JavaScript.

Vite is used only as a local dev server.

## How to run

You need **Node.js** (20.19+ or 22.12+) and **npm**.

```bash
npm i
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
